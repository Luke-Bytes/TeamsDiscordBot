## 4. Incentive and scoring contract

Normal win is first and independent; no extra Elo/XP, rank, bonus for loss or persistent leaderboard. A player who skips missions to defend nexus can still win Anni, but cannot receive a perfect impostor result. A player who completes five rather than four gets no extra reward; display actual count only. Never rank losing-team deception above any normal winner; partial achievements are descriptions, not fungible points. No need to take an objectively losing fight or obstruct a teammate to meet a mission; if opportunity never safely arises, accept an incomplete/neutral result. Don't encourage prolonging a match to finish tasks or trigger a slot.

Assignment status:
- Physical pass iff at least four distinct accepted assigned missions. Fail if fewer than four and even adding technical/objective voids cannot reach four. Inconclusive if fewer than four but accepted + eligible void count >= four; unverified/declined/missing/disputed claims are NOT voids. Never reduce denominator to three or fewer. If review timed out ordinarily, unverified means no credit; if verified bot-wide outage made submission/review impossible, mark affected otherwise eligible claims technical void, never auto-pass.
- Voice pass iff the one required slot was actually applied to the full intended eligible group with meaningful verified occupancy for at least 60 seconds of the planned 120 (or other approved test threshold). Slot not reached before end, inaccessible pool, insufficient verified duration due to voluntary exits/moderation/end or API/recovery failure => void/inconclusive, not a pass. A recorded deliberate rule breach proven through established moderation process can invalidate eligibility; do not infer malicious intent from disconnects. Auto fallback earns same credit as manual. No player-supplied voice proof.
- Combined assignment PASS only if both physical and voice pass; FAIL if either fails; otherwise INCONCLUSIVE. Scenario abort => VOID independent of axes. Unknown winner never converted to loss.

Deduction: exposure is inclusion in a definitively accused set (section 8). Valid complete tally and absence from set = hidden; incomplete tally and absence = inconclusive, never hidden. A definite accused impostor can be exposed even when another seat is unresolved; invalid quorum makes all exposure statuses inconclusive. Final presentation uses component statuses not a fabricated binary.

| Own team won | Assignment pass | Hidden | Result label (proposed) |
| --- | --- | --- | --- |
| yes | yes | yes | Perfect Impostor Victory |
| yes | yes | no | Won the War, Cover Blown |
| yes | no | yes | Won the War, Assignment Incomplete |
| yes | no | no | Won the War, Exposed |
| no | yes | yes | Successful Deception (match lost) |
| no | yes | no | Missions Complete, Cover Blown |
| no | no | yes | Stayed Hidden, Assignment Incomplete |
| no | no | no | Assignment Incomplete, Exposed |

Any unknown/inconclusive axis: show known achievements plus neutral "Scenario result inconclusive"; no perfect victory. Cancellation or integrity failure: "Scenario void", normal winner if known remains authoritative. If scoring finishes before winner is reported, store immutable assignment and deduction; defer final combined label until winner is confirmed; no indefinite vote/claim extension. Winner correction before save recomputes label only, never changes claims/votes; reveal correction once, persistence uses authoritative latest winner. No losing bonus. Innocents: normal result plus number exposed, all/partial/none only for valid complete accusation set; if incomplete show definite exposed count and unresolved seats; no individual innocent objective.

A redraw must honor the same caps (released old offers re-enter pool). ## 8. Voting and First Impressions

N is frozen assigned count, not number of surviving impostors. Every frozen eligible same-team participant (including impostors) may privately select up to N distinct teammates, excluding self. Ballot is unordered, equal weight 1 per selection; no duplicates/enemy/new player/unknown ID. One atomic submit with optional edit until fixed deadline; no implicit submit on opening/select changes. Explicit abstain recorded separately from absent; blank draft not a vote. Use Discord IDs, safe escaped labels, accessible list/pagination and final review; v1 max 20 avoids >25 option limit but validator/tests must reject oversized unsupported roster or implement paging before increasing cap. No raw vote list, no counts/partial results before both ballots lock. No public individual turnout; generic countdown/one reminder to all. Server owner-bound actions and token/revision, no organiser casting for someone else. No evidence/reviewer notification until both teams locked, not just own team.

First Impressions after role card before actual-play anchor; optional, never delays match, same ballot constraints, no tally during play; freeze with actual start. If role leaked or match void, predictions not used for public awards. No effect on gameplay/final tally. Final meeting four minutes (within approved range) separate team voice + optional text, then 90s vote, no requirement to speak, no demands to show cards, targeted harassment or private evidence. All eligible players count equally, including impostors because deception includes misdirection. No secret innocent-only tally. In small teams collusion still possible; monitor pilot.

### Tally (pure deterministic)

1. Denominator R = original frozen team size, never reduce for absentee, disconnect, abstain, dropout or strategic unregister. Positive-ballot quorum = floor(R/2)+1 distinct eligible voters with at least one valid selection. Abstain counts for participation only, not quorum. Revalidate complete ballots at lock; corrupted ballot rejected, no partial salvage. If quorum not reached, whole team deduction inconclusive, no exposure or hidden credit.
2. Count positive votes per frozen candidate. Fill N seats by descending count, never zero votes. If a tied group fits remaining seats, all in that group definite accused. If group straddles cutoff, none of that group definite accused, remaining seats unresolved. No arbitrary ID/random tiebreak, no runoff in v1; avoids additional waiting and tactical disclosure. If fewer positive suspects than N, unresolved seats. All counts deterministic independent of input order.
3. Valid quorum + N definite accused => complete; otherwise incomplete. Definite accused impostors exposed, all others inconclusive when incomplete. With complete set, each unaccused impostor hidden; innocent result all/some/none exposed. No claim "undetected" merely because 0 votes if tally incomplete.
4. Examples: R=10, N=2, 5 positive ballots + 2 abstains => quorum failure. Six positive ballots, scores A=5,B=4,C=4 => A definite, one unresolved; if A is impostor expose A, others inconclusive. Six positive ballots, A=5,B=4,C=1 => A/B accused, complete. R=8,N=1, five positive ballots, top tied => no definite suspect, inconclusive. Two impostors cannot achieve quorum alone in 9-15 group, but can sway innocents; acceptable social play unless collusive proof fabrication.
5. Awards private by default: Psychic = complete early ballot exactly correct set N; Sixth Sense = at least one correct early, not Psychic; Master Detective = complete final ballot exactly correct on adjudicable team; Easily Fooled = privately lost early correct suspect in final ballot (both submitted); Red Herring = optional consented most suspected innocent (ties shared, no shaming); Master of Deception = assignment pass and complete deduction with zero individual votes. No awards for invalid/missing ballots, no raw selections exposed, no award-based competitive points. Public only aggregate early/final correct guesses and consented fun highlights after reveal. Avoid revealing other votes via small-cell counts: public definite accused names and aggregate exposed count, not per-candidate totals or witness identities; private own ballot summary.

## 9. Low-friction evidence and community adjudication

Evidence is support for a claim, not Minecraft telemetry. Screenshot may establish visible scene but not who acted, why, timing, exact nonstackable count, class, persuasion, consent or non-consumption. No external image recognition, no recording requirement, no asking innocent players to document their own gameplay. Optional observers only after lock. - Prefer actual witness path to avoid screenshots where attribution cannot be inferred. For W+S independent screenshot review plus W covers missing attribution/condition; both must answer yes. Two yes from same person never count. Any substantive no => disputed, no automatic credit; insufficient evidence or didn't see/absent => unverified; clearly invalid cap/mismatch => rejected. Cannot prove truth or eliminate innocent friends colluding. No rewards that make gaming verification valuable. Do not infer dishonesty from absent reviewer. Claims show claimant only their own accepted/unverified/rejected/disputed/void summary after closure, not reviewer identities. Public summaries don't name witnesses or share raw evidence.
- Attachment handling: only actual Discord interaction attachments in authorised owner-bound private path (check installed discord.js attachment option/modal support; if unavailable use existing slash attachment command with ephemeral reply, never public channel uploads). No accepting arbitrary URLs, no fetching private external resources or sending to Navi. Don't log attachment URLs; Discord CDN links can expire and DM messages persist outside bot control. Prefer in-memory bounded image buffer/short-lived access for reviewer after lock, no durable screenshots or raw attachments in active snapshots; delete bot-controlled review messages/cache at final lock/within 24h (earlier if possible), report deletion failures, no guarantee deletion from users' clients or platform. No raw evidence in public history; if data lost by bot fault, affected claim technical void only if eligible submission recorded. Keep private voting/claim records only through adjudication and safe save/retry, propose purge within 24h of completed/aborted match; unresolved safety journal retained independently until resolved.
- Two-minute claim and two-minute review hard windows, one reminder maximum, no mid-game forms needed. One person's absent witness does not delay reveal. If 3 impostors submit 4 claims each, 24 independent confirmations per team => with 15 innocents and max 3 each possible in aggregate but real actual witnesses may cluster. If all 4 events observed by one teammate, max 3 makes one unverified: test workload and approval before release; don't inflate caps silently. If proof burden too high, pilot feedback and explicit approval of lower assurance rather than automatic acceptance.

| Vote empty, all abstain, low positive quorum, cutoff tie, fewer suspects than N, valid all/no/some exposed, reordered input, max ballot | Deterministic tally and statuses, no random culprit, no hidden credit from incomplete tally; rejects self/duplicate/enemy/unknown; no raw vote exposure. |
| Pregame optional missed/edited, evidence before both ballots close, user demands role proof, text-only participant | No delay/score effect from early prediction; private awards only valid ballots; no premature reveal/reviewer message; accessible text option, moderation normal. |
| Claim no witness, screenshot only, same witness twice, fellow impostor nominated, duplicate event/image, false proof, disagreement, reviewer absent, attachment expired/oversize/malformed | No automatic pass, no leakage through nomination response, threshold enforced, bounded workload; unverified/disputed/rejected/void distinguished; no arbitrary URL/AI or public evidence; claims close on deadline. |
| All eight binary combinations + assignment physical/voice fail/pass/unknown, unknown winner, void/cancel, correction | Truth table exactly, no full victory if failed/unknown; innocent count separate; no bonus for loss, no rating changes outside explicit policy; result projection stable and secret-free. |
| Postgame end before play anchor, repeated end, winner reported first, shutdown early, emergency stop, MVP/plan capture, after-lock normal VC movement | No live effects without anchor; bounded neutral result, normal path once, safety gate nonwaivable, ordinary winner/MVP/persistence intact. |
| Other seven modes, none, guide and knowledge manifest | No changed pregame checks, normal Elo/gameType unchanged, upcoming preview only until enabled, no scenario secrets in Navi; normal cancellation/recovery regressions pass. |
